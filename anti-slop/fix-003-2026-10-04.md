# Dashboard composition refinement

Scope: development dashboard only. No production deployment, push, migration, database mutation, payment submission, or WhatsApp action. Existing unrelated changes preserved.

Direction: HATO's emerald/slate operational interface, using the user's production screenshot as composition reference. ENERGY 1 / RHYTHM 2 / MOTION 1.

## Changes and reasons

- Bounded cycle header and separate date strip keep the selected week, status, action, and deadlines together without oversized typography.
- Independent left stack (rotation, recent orders) and right stack (finance, workflow) remove the gap between a short rotation card and the recent-order list. Split starts at 896px of available content, not viewport width.
- Finance's received/outstanding values use semantic emerald/rose surfaces for quick comparison; auto-fit cells stack when the panel is narrow. Unknown purchase value and incomplete-balance warning remain explicit.
- Workflow is separate from finance, making its current next action and remaining stage links discoverable. Arrows indicate navigation, not decoration.
- Existing Geist typography, slate surfaces, 12px panel radii, variant rows, actual dates, and real cycle data remain unchanged. No new assets or fabricated stock/leftover quantities.
- Recent-order rows now open the existing payment detail for their actual order ID. The old Orders destination ignored orderId; the explanatory subtitle now names the interaction. The all-orders link still opens Orders.
- No schedule-management link is added because the current dev cycle screen does not render that function.
